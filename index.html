📚 DAA Algorithm Reference & Complexity Sheet

Comprehensive comparative summary of the graph traversal and pathfinding algorithms implemented in this project:

Algorithm Data Structure Time Complexity Space Complexity Optimality
BFS (Breadth-First) FIFO Queue O(V + E) O(V) ✅ Optimal for unweighted graphs
DFS (Depth-First) LIFO Stack / Recursion O(V + E) O(V) ❌ Not optimal (wanders into dead ends)
Dijkstra's Min-Priority Queue (Min-Heap) O((V + E) log V) O(V) ✅ Guaranteed optimal for non-negative weights
A* Search Min-Priority Queue + Heuristic f = g + h O((V + E) log V) (worst-case) O(V) ✅ Guaranteed optimal if h(n) is admissible

Heuristic Function in A*

This implementation uses Manhattan Distance: h(n) = |x_n - x_end| + |y_n - y_end|, which is admissible (never overestimates the true cost in a 4-connected grid graph), ensuring that A* explores significantly fewer states than Dijkstra while guaranteeing the shortest path.

Procedural Maze Generation

• Recursive Backtracking (DFS): Generates deep, winding corridors with few branches.
• Randomized Prim's: Builds a spanning tree with high branching factor and many short dead ends.
• Kruskal's Algorithm: Uses Disjoint Set Union (DSU) to generate a uniform spanning tree.
